# Dipstick sticker outlines

Ten original, editable SVG sticker silhouettes for the Dipstick sticker-sheet site.

## Shape index

1. Soft rectangle
2. Capsule
3. Scalloped badge
4. Cloud blob
5. Wobbly oval
6. Splat
7. Classic starburst
8. Comic burst
9. Zap burst
10. Melted label

Every individual SVG uses a `512 × 512` viewBox and contains one primary closed path with `id="sticker-shape"`. The default appearance is a white fill with a black 12-unit outline. Change the path's `fill`, `stroke`, and `stroke-width` attributes to restyle it.

The shapes have comfortable edge clearance for shadows, thicker strokes, or print bleed. For a cutline-only version, set `fill="none"`.
